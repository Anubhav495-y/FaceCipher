# WiDS - FaceCipher
This project is focused on exploring and implementing various techniques in image processing, object detection, and facial recognition.
<br>

## Project Overview
 Over the course of four weeks, the project leverages different models and frameworks to develop a robust system for facial recognition and analysis.

## Roadmap

### Week 1: Python & ML Basics
- **Goal**: The [first week](Week1) is focused on learning essential machine learning libraries such as NumPy, Pandas, and Matplotlib, which are crucial for data manipulation and visualization. This is followed by an introduction to the foundational concepts of machine learning, including regression. Although some topics may not be directly incorporated into the final project, they strengthen the understanding of machine learning principles and provide valuable exposure to computer vision.
- **Topics covered**:
1. We begin by covering the basics of [Python](https://scrimba.com/learn/python) to lay foundation
2. We cover essential modules [numpy](https://numpy.org/doc/stable/user/absolute_beginners.html), [Pandas](https://www.w3schools.com/python/pandas/default.asp), [Matplotlib](https://www.w3schools.com/python/matplotlib_intro.asp)
3. Our first ML concept will be Linear Regression, a powerful technique for modeling relationships between variables.
4. Then we explore [Logistic Regression](https://github.com/Anubhav495-y/FaceCipher/blob/3f0a0d689dac1f3a1e68a36bd4b180cb454fd43d/Week1/BinaryLogisticR.ipynb), a fundamental method for binary classification tasks.
5.Week 1 ends with [Assignment](https://github.com/Anubhav495-y/FaceCipher/tree/3f0a0d689dac1f3a1e68a36bd4b180cb454fd43d/Week1/Assignment%201) to sum up whole week learning.

### Week 2 : Introduction to Neural networks and YOLOv8
- **Goal** :This week focuses on Deep Learning, covering essential frameworks such as TensorFlow and PyTorch, core neural network concepts, and an introduction to the YOLOv8 architecture for object classification. Hands-on experiments on multiple datasets are used to reinforce learning.
- **Topics covered** :
1. Deep learning framework ; tesorflow
2. Concepts of Neural Networks 
3. YOLOv8, focusing on its capabilities for object detection and classification.
4. The Assignments to practice our skills to reinforce our understanding.

### Week 3 : 
- **Goal** : This week focuses on Convolutional Neural Networks (CNNs) and image preprocessing using OpenCV, covering core CNN concepts and essential preprocessing techniques such as resizing, normalization, blurring, and noise removal. Practical exercises on multiple datasets are used to strengthen understanding of CNN model training.
- **Topics covered** :
1. OpenCV ; essential for preprocessing the raw image data.
2. Exploring Convolutional Neural Network, the most efficient NN to deal with image data.
