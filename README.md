# WiDS - FaceCipher
This project is focused on exploring and implementing various techniques in image processing, object detection, and facial recognition.
<br>

## Project Overview
 Over the course of four weeks, the project leverages different models and frameworks to develop a robust system for facial recognition and analysis.

## Roadmap

### Week 1: Python & ML Basics
-**Goal**: The [first week](Week1) is focused on learning essential machine learning libraries such as NumPy, Pandas, and Matplotlib, which are crucial for data manipulation and visualization. This is followed by an introduction to the foundational concepts of machine learning, including regression. Although some topics may not be directly incorporated into the final project, they strengthen the understanding of machine learning principles and provide valuable exposure to computer vision.
-**Topics covred**:
1. We begin by covering the basics of [Python](https://scrimba.com/learn/python) to lay foundation
2. We cover essential modules [numpy](https://numpy.org/doc/stable/user/absolute_beginners.html), [Pandas](https://www.w3schools.com/python/pandas/default.asp), [Matplotlib](https://www.w3schools.com/python/matplotlib_intro.asp)
3. Our first ML concept will be Linear Regression, a powerful technique for modeling relationships between variables.
4.Then we explore [Logistic Regression](FaceCipher\Week1\BinaryLogisticR.ipynb), a fundamental method for binary classification tasks.
5.Week 1 ends with Assignment to sum up whole week learning.
