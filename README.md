# WiDS - FaceCipher
This project is focused on exploring and implementing various techniques in image processing, object detection, and facial recognition. Over the course of four weeks, the project leverages different models and frameworks to develop a robust system for facial recognition and analysis.
<br>

# Week 1 
The first week is focused on learning essential machine learning libraries such as NumPy, Pandas, and Matplotlib, which are crucial for data manipulation and visualization. This is followed by an introduction to the foundational concepts of machine learning, including regression. Although some topics may not be directly incorporated into the final project, they strengthen the understanding of machine learning principles and provide valuable exposure to computer vision.
<br>
1. We begin by covering the basics of python to lay foundation <br>
2. We cover essential modules numpy , pandas , matplotlib
3. Our first ML concept will be Linear Regression, a powerful technique for modeling relationships between variables.
4.Then we explore Logistic Regression, a fundamental method for binary classification tasks.
5.Week 1 ends with Assignment to sum up whole week learning.
